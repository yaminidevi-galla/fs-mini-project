# SmartExam - Full Working + Teacher Registration + Registration Choice

This version is based on SmartExam Full-Working and includes:
- Student registration
- Teacher registration
- Student/Teacher choice popup before registration
- Login with role-based redirect
- Teacher dashboard
- Exam creation
- My Exams
- Question management
- Teacher results
- Student dashboard/exam/result pages
- MongoDB Atlas configuration through .env

## Run
1. Open the project folder in VS Code.
2. Run `npm install`.
3. Create `.env` from `.env.example` and add your own MongoDB URI and JWT secret.
4. Run `node app.js`.
5. Open `http://localhost:3000`.

Do not put your real `.env` file or MongoDB password into a public ZIP/repository.
